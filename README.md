# E-commerce DB - MariaDB

Sistema de gestion de base de datos para e-commerce con productos, clientes, pedidos, pagos y notas de credito.

### Tablas:
- productos (stock)
- clientes
- pedidos / facturas
- detalle_pedidos
- pagos / recibos (RC)
- notas_credito (NC)

### Tecnologia:
MariaDB / MySQL
